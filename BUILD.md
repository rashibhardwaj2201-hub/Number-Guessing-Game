# Number Guessing Game

## Description
A simple C++ number guessing game.

The computer generates a random number
between 1 and 100.

The user guesses the number and receives
high or low hints.

## Features
- Random number generation
- High and Low hints
- Attempt counter
- Loop-based execution

## Compilation
g++ main.cpp -o game

## Execution
game.exe
